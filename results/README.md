# results/

Experiment output. **These files are the project's deliverable** — the code exists to produce them (`docs/EVALUATION.md`).

## Rules

**Every CSV carries a header block** with the seed, chaos profile, worker count, code revision, and date. A chart that cannot be regenerated from its seed is not evidence (`docs/CONVENTIONS.md` §6).

**Every chart is labeled REAL / MIXED / SIMULATED** in its title, not a footnote:

- **REAL** — physically distinct GPUs
- **MIXED** — some real GPUs, some mock workers
- **SIMULATED** — mock workers only

Never present a simulated scaling curve as measured. Stating the distinction plainly reads as rigor; being caught blurring it destroys the credibility of every other number in the project.

**Every number quoted in the README must be traceable to a committed CSV here.**

## Layout

```
results/
├── adapter-<device>.json     device capability dumps (Phase 0 onward)
├── e1-scaling/               throughput vs. worker count
├── e2-utilization/           gpu/transfer/idle breakdown (+ accumulation-off control)
├── e3-fault-tolerance/       fleet-kill timelines
├── e4-byzantine/             detection vs. overhead (+ false-positive control)
├── e5-stragglers/            completion CDFs, speculation on/off
├── e6-egress/                coordinator egress, P2P on/off
├── e7-efficiency/            achieved vs. peak GFLOP/s per vendor
└── scratch/                  gitignored — throwaway runs
```

Raw CSVs are committed. Rendered charts (`*.png`, `*.svg`) are gitignored and regenerated by the Phase 7 reproduction script (step 7.6).
